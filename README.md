# move-client-android

[![No Maintenance Intended](http://unmaintained.tech/badge.svg)](http://unmaintained.tech/)

:iphone: The Android app of Move, a service that shows you the nearest places selling what you need and delivers your order wherever you are.

## Usage
Open the project in [Android Studio](https://developer.android.com/studio) and run the `app` module on an emulator or device.
